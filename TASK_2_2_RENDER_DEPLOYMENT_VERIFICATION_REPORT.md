### Why Render Has Not Automatically Deployed
1. **Render Free Tier Auto-Deploy Policy:** In many Render Blueprint setups or free tier configurations, auto-deploy is disabled by default to prevent exhausting build hours on frequent git commits.
2. **Webhook Triggering:** Blueprints often require a manual "Sync Blueprint" trigger from the web dashboard after repo branch updates.
3. **Container Cache:** Render continues serving the existing healthy container until a new deployment successfully completes its build and health check phase.
